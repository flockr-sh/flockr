# Contributing

Pull requests are welcome, including ones written with AI. You're
responsible for what you submit:

- Fix a real problem, and say how to reproduce it.
- Keep each pull request to one change.
- Run `just ci` and make sure it passes.
- Be able to explain every line.

Open an issue before starting a large feature or a change to how flockr
looks or works.

`AGENTS.md` covers the toolchain, layout, and code conventions.
